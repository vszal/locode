```DESIGN.md

envcfg — layered configuration loading

Overview
envcfg assembles a single configuration dictionary from three layers:
- defaults (dict) — lowest priority
- TOML file (path, optional) — medium priority
- environment variables (prefix, optional) — highest priority

Later layers override earlier ones key-by-key. A TOML file that sets only one key leaves the other defaults intact.

Public API
envcfg.load(defaults: dict, toml_path: str | None = None, prefix: str = "APP", env: dict | None = None) -> dict
- defaults: dict of nested config values (will be deep-copied)
- toml_path: path to a TOML file; missing file is silently skipped
- prefix: env prefix for nested keys (e.g. prefix="APP" → APP__SERVER__PORT)
- env: dict of environment strings to read; defaults to os.environ
- returns: merged dict with same nesting as defaults

envcfg.ConfigError(Exception)
Raised when:
- an env key has no matching default (possible typo)
- an env value cannot be coerced to the expected type

Coercion rules
Env values are strings and are coerced to match the type of the existing default for that key. Supported types: int, float, bool, str.

- int: env string must be a valid integer literal (e.g. "42", "-7").
- float: env string must be a valid float literal (e.g. "3.14", "-0.5").
- bool: env string must be one of: "true", "false", "yes", "no", "1", "0" (case-insensitive).
- str: env string is used as-is.

If coercion fails, ConfigError is raised with a message naming the key and the expected type.

Precedence rules
1. Start with a deep copy of defaults.
2. Apply TOML values: for each key in the TOML, merge into the current dict (later keys override earlier ones at the same level).
3. Apply env values: for each env key, coerce to the type of the current dict value at that key. If the key does not exist in the current dict, raise ConfigError. If coercion fails, raise ConfigError.

Nested keys are addressed via prefix + "__" + uppercased path. Example: prefix="APP", path="server.port" → env key "APP__SERVER__PORT".

Error reporting
envcfg raises ConfigError for:
- missing env key (no default)
- failed coercion

The caller should catch ConfigError and report all errors at once.```tool
