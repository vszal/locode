If missing, this layer is skipped.\n        prefix: Environment variable prefix (e.g. \"APP\" -> APP__SERVER__PORT).\n        env: Optional dict of environment variables. If None, os.environ is used.\n\n    Returns:\n        Merged configuration dictionary.\n\n    Raises:\n        ConfigError: If any environment variable has no matching default key\n                     or cannot be coerced to the expected type.\n    \"\"\"\n```\n\n### Exception: `ConfigError`\n\n```python\nclass ConfigError(Exception):\n    \"\"\"Raised when an environment variable cannot be coerced or has no default.\"\"\"\n    def __init__(self, key: str, expected: str):\n        self.key = key\n        self.expected = expected\n        super().__init__(f\"Invalid config: {key} = {expected} (expected: {expected})\")\n```\n\n## Precedence Rules\n\n1. **Defaults** are always included unless overridden.\n2. **TOML** values override defaults for the same key.\n3. **Environment** values override both defaults and TOML.\n4.
