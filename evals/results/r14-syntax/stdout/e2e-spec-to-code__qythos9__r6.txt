# DESIGN.md — envcfg specification

## Overview

envcfg is a small Python module that assembles one configuration dictionary from three layers:
- **defaults** (lowest priority): a plain dict supplied by the caller
- **TOML file** (medium priority): parsed with `tomllib`; missing files are ignored
- **environment variables** (highest priority): read under a caller‑chosen prefix

Later layers override earlier ones key‑by‑key, so a TOML file that sets only one key leaves the other defaults intact.

## Public API

```python
from envcfg import ConfigError, load

def load(
    defaults: dict,
    toml_path: str | None = None,
    prefix: str = "APP",
    env: dict[str, str] | None = None,
) -> dict:
    """
    Merge defaults, an optional TOML file, and environment variables.
    
    - defaults: dict of base values (any JSON‑serializable types).
    - toml_path: path to a TOML file; if missing, that layer is skipped.
    - prefix: string prefix for environment variable names.
    - env: dict mapping env var names to string values; if None, os.environ
      is used.
    
    Returns a merged dict with the same nesting as defaults, but with
    values possibly overridden by TOML or env vars.
    
    Raises ConfigError if:
      - an env var is present but has no corresponding default key, or
      - an env var cannot be coerced to the type of its default.
    """
```

### Return value

A plain `dict` with the same top‑level keys as `defaults`. Nested tables are represented as nested dicts. Values are coerced to the type of the default (see Coercion Rules).

### Exceptions

```python
class ConfigError(Exception):
    """Raised when an environment variable is invalid."""
    def __init__(self, key: str, expected: str, got: str | None = None):
        self.key = key
        self.expected = expected
        self.got = got
        super().__init__(
            f"Invalid config for '{key}': expected {expected}"
            + (f" but got '{got}'" if got is not None else "")
        )
```

## Precedence Rules

1. **Defaults** are always present and form the base.
2. **TOML** values are applied next, overriding defaults for matching keys.
3. **Environment** values are applied last, overriding both defaults and TOML.

If a key exists in multiple layers, the highest‑priority layer wins. If a key exists only in a higher layer, the lower layers are ignored for that key.

## Coercion Rules

Environment variables are strings and must be coerced to match the type of the default value for that key. Supported types and their coercion rules:

| Default type | Coercion rules (case‑insensitive) |
|--------------|------------------------------------|
| `int`        | `-?\\d+` (optional minus, one or more digits) |
| `float`      | `-?\\d+(\\.\\d+)?` (optional minus, digits, optional decimal part) |
| `bool`       | `true`, `false`, `yes`, `no`, `1`, `0` |
| `str`        | any non‑empty string (the raw value) |
| other types  | not supported; will raise `ConfigError` |

If coercion fails, `ConfigError` is raised with the offending key, the expected type name, and the raw string (if any).

### Nested keys

Nested configuration is addressed via a prefix and double underscores:
- With prefix `APP`, the key `server.port` in defaults becomes environment variable `APP__SERVER__PORT`.
- The same applies to any depth: `database.connection.timeout` → `APP__DATABASE__CONNECTION__TIMEOUT`.

## Error Reporting

- A single `ConfigError` is raised per invalid environment variable.
- The error message includes:
  - The offending key (e.g., `"APP__SERVER__PORT"`).
  - The expected type (e.g., `"int"`).
  - The raw value (e.g., `"abc"`), if present.
- Multiple errors are reported as separate exceptions; callers should wrap `load` in a `try/except` and collect or re‑raise as needed.

## Constraints

- Python 3.10+
- Standard library only (`tomllib` for TOML parsing)
- Module size: ≤ 150 lines
- Tests must cover:
  - Precedence order (defaults → TOML → env)
  - Nested overrides
  - All coercion types (int, float, bool, str)
  - Both error cases (coercion failure, missing default)
  - Missing TOML file (should be ignored)
