# DESIGN.md — envcfg specification

## Overview

envcfg is a small Python module that assembles one configuration dictionary from three layers:
- **defaults** (lowest priority): a plain dict supplied by the caller
- **TOML file** (medium priority): parsed with `tomllib`; missing files are silently ignored
- **environment variables** (highest priority): read under a caller‑chosen prefix, with nested keys joined by `__` and uppercased

Later layers override earlier ones key‑by‑key, so a TOML file that sets only one key leaves the other defaults intact.

## Public API

```python
class EnvCfgError(Exception):
    """Raised when a configuration value is invalid or an env key has no default."""
    pass

def load(
    defaults: dict,
    toml_path: str | None = None,
    prefix: str = "APP",
    env: dict[str, str] | None = None,
) -> dict:
    """
    Merge defaults, optional TOML, and environment variables.
    
    - defaults: dict of base values (any JSON‑serializable types).
    - toml_path: optional path to a TOML file; if missing, that layer is skipped.
    - prefix: string prefix for env vars; nested keys are joined with '__' and uppercased.
      Example: prefix='APP', key='server.port' → env var 'APP__SERVER__PORT'.
    - env: optional dict mapping env var names to strings; if None, os.environ is used.
    
    Returns the merged dict with the same nesting as defaults.
    
    Raises EnvCfgError with a message naming the offending key and what was expected
    if:
      - an env value cannot be coerced to the type of the default, or
      - an env key is present but has no corresponding default (possible typo).
    """
```

## Precedence Rules

1. **Defaults** are always present and form the base.
2. **TOML** values are applied on top of defaults, key‑by‑key. If a TOML key does not exist in defaults, it is simply added (no error).
3. **Environment** values are applied last, overriding both defaults and TOML for matching keys.
4. If an environment key matches a nested path, only that leaf is overridden; sibling keys remain untouched.
5. A missing TOML file is not an error; the layer is skipped entirely.

## Coercion Rules

Environment variables are strings and must be coerced to match the type of the existing default value for that key. Supported types and their coercion rules:

| Target type | Accepted string values (case‑insensitive) |
|-------------|--------------------------------------------|
| `int`       | any valid integer literal (e.g. `"42"`, `"-7"`) |
| `float`     | any valid float literal (e.g. `"3.14"`, `"-0.5"`) |
| `bool`      | `true`, `false`, `yes`, `no`, `1`, `0` |
| `str`       | any non‑empty string (passed through unchanged) |

Coercion is strict:
- If the string cannot be parsed as the target type, raise `EnvCfgError` with a message like `"key: expected <type>, got '<value>'"`.
- If an environment key is present but there is **no** corresponding default (i.e., the key never appears in `defaults` or any TOML layer), also raise `EnvCfgError` with a message like `"key: no default for this configuration option"`. This prevents silent acceptance of misspelled variable names.

Nested keys are handled recursively: the coercion is performed on the leaf value, and the path is reconstructed from the prefix and the nested sequence.

## Error Reporting

- A single custom exception `EnvCfgError` is used for all configuration problems.
- The exception message always includes the offending key path and a brief description of what was expected versus what was found.
- Multiple errors in one load are **not** accumulated; the first error encountered is raised immediately. This keeps failures fast and focused.
- Errors are never silently ignored; they must be handled by the caller.

## Implementation Constraints

- Python 3.10+ only.
- Standard library only; use `tomllib` for TOML parsing.
- Keep the module under ~150 lines.
- Provide comprehensive tests covering:
  - precedence order (defaults < TOML < env),
  - nested overrides,
  - every coercion type,
  - both error cases (bad coercion, missing default),
  - missing TOML file (should be skipped).
