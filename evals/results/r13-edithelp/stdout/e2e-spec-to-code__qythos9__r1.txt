A table in TOML becomes a nested dictionary. A nested key is addressed from the environment by joining the path with a double underscore and upper-casing it, under a prefix the caller chooses.\n\n**Example:** With prefix `APP`, the environment variable `APP__SERVER__PORT` sets the `port` key inside the `server` table.\n\n## Coercion Rules\n\nEnvironment variables arrive as strings and must be coerced to match the type of the default already present for that key.\n\nSupported types:\n- `int`\n- `float`\n- `bool`\n- `str`\n\n### Boolean coercion\n\nBooleans accept the obvious `true`/`false` spellings in either case, plus `1`/`0`, `yes`/`no` (case-insensitive).\n\n### Error on coercion failure\n\nA value that cannot be coerced is an error, not a silent fallback.\n\n### Error on missing default\n\nAn environment key with no corresponding default is also an error — it is almost always a typo, and silently accepting it is how a misspelled variable goes unnoticed.\n\n## Error Reporting\n\nThe loader raises a single custom exception type, `envcfg.ConfigError`, carrying a message that names the offending key and says what was expected.\n\nSeveral problems in one load should be reported together rather than one at a time, so the caller fixes them all in one pass.\n\n## Public API\n\n### Function signature\n\n```python\ndef load(\n    defaults: dict,          # lowest-priority defaults\n    toml_path: str | None,   # optional path to TOML file\n    prefix: str,             # environment prefix (e.g. \"APP\")\n    env: dict[str, str] | None = None,  # optional env mapping; defaults to os.environ\n) -> dict:\n```\n\n- A missing TOML file is **not** an error; the layer is simply skipped.\n- The function returns the merged dictionary.\n- Any configuration problem raises `envcfg.ConfigError`.\n\n### Exception class\n\n```python\nclass ConfigError(Exception):\n    def __init__(self, key: str, expected: str, actual: str | None = None):\n        self.key = key
