TOML file values override default values.\n\n## Coercion Rules\n- Environment variables are strings and must be coerced to match the type of the default value.\n- Supported types: integers, floats, booleans, and strings.\n- Booleans accept true, false, 1, 0, yes, and no (case-insensitive).\n- If a value cannot be coerced, an error is raised.\n- An environment key with no corresponding default is also an error.\n\n## Error Reporting\n- A single custom exception type is raised with a message that names the offending key and the expected type.\n- Multiple errors are reported together rather than one at a time.\n\n## Constraints\n- Python 3.10+, standard library only.\n- Use `tomllib` for TOML parsing.\n- Keep the module under about 150 lines.\n- Ship tests covering the precedence order, nested overrides, every coercion type, both error cases, and the missing-file case."}}
