```All tests pass. The three bugs in `textkit.py` were:

1. **`word_wrap`** – the condition for adding a word to the current line used `< width` instead of `<= width`. This caused a line that would exactly fit the width to be split prematurely. Changed:
   ```python
   elif current_len + 1 + len(word) < width:
   ```
   to:
   ```python
   elif current_len + 1 + len(word) <= width:
   ```

2. **`truncate`** – the cut point was computed as `limit - len(suffix) + 1`, which made the result one character too long. The correct formula is simply `limit - len(suffix)`. Changed:
   ```python
   cut = limit - len(suffix) + 1
   ```
   to:
   ```python
   cut = limit - len(suffix)
   ```

3. **`title_case`** – small words (like "a") were lowercased even when they appeared as the first word of the sentence. The spec requires the first word to always be capitalized. Added an index check:
   ```python
   for i, word in enumerate(words):
       lower = word.lower()
       if lower in SMALL_WORDS:
           result.append(lower.capitalize() if i == 0 else lower)
       else:
           result.append(lower.capitalize())
   ```
