1. **Last record without trailing separator**: If the text ends with a record (no blank line after it), that record is never appended because there's no blank line to trigger it.

2. **Extra blank lines**: Multiple consecutive blank lines will append an empty dict for each blank line, creating spurious empty records.

The fix requires restructuring the control flow. Instead of appending on every blank line, we should:
- Track whether we're currently building a record (i.e., `current` is not empty)
- Only append `current` when we encounter a blank line **and** `current` is not empty
- After processing all lines, check if `current` is not empty and append it (to handle the last record without trailing separator)
- Never append an empty dict (which would happen with multiple blank lines)

def parse_records(text):
    """Parse `text` into a list of record dicts.

    Format: `text` is a sequence of lines. Each non-blank line is a
    "key: value" pair belonging to the current record -- the key is
    everything before the first colon, the value is everything after,
    both stripped of surrounding whitespace. One or more consecutive
    blank lines separate one record from the next (multiple blank lines
    in a row are equivalent to a single separator and never produce an
    empty record on their own). A record with at least one field is
    included in the result, in the order it was encountered, as a dict
    of its fields. Leading/trailing blank lines in `text` do not produce
    empty records. If `text` has no fields at all, an empty list is
    returned.
    """
    records = []
    current = {}
    for raw_line in text.splitlines():
        line = raw_line.strip()
        if line == "":
            if current:
                records.append(current)
                current = {}
        else:
            key, _, value = line.partition(":")
            current[key.strip()] = value.strip()
    if current:
        records.append(current)
    return records
```

- Added `if current:` check before appending on blank lines to avoid empty records
- Added `if current:` check after the loop to handle the last record without trailing separator
- This ensures multiple blank lines only append once (when `current` is empty, we don't append)
