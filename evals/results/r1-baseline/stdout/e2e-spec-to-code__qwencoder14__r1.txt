The environment variables take precedence over the TOML file, which in turn takes precedence over the defaults.\n\n## Public API\n\n- `load_config(defaults, toml_path=None, env_prefix, env_mapping=os.environ)`\n  - `defaults`: A dictionary of default configuration values.\n  - `toml_path`: An optional path to a TOML configuration file.\n  - `env_prefix`: A prefix for environment variables.\n  - `env_mapping`: An optional dictionary of environment variables (default is `os.environ`).\n  - Returns a merged configuration dictionary.\n\n## Precedence Rules\n\n1. Environment variables\n2. TOML file\n3. Defaults\n\n## Coercion Rules\n\n- Integers, floats, booleans, and strings are supported.\n- Booleans accept `true`, `false`, `1`, `0`, `yes`, `no`.\n- A value that cannot be coerced is an error.\n- An environment key with no corresponding default is also an error.\n\n## Error Reporting\n\n- Raises a single custom exception type carrying a message that names the offending key and says what was expected.\n- Reports several problems in one load together rather than one at a time.\n"}}

{"name": "write_file", "args": {"path": "envcfg.py", "content": "import os\ntomllib = None\n\nclass ConfigError(Exception):\n    pass\n\ndef load_config(defaults, toml_path=None, env_prefix, env_mapping=os.environ):\n    config = defaults.copy()\n    \n    if toml_path:\n        try:\n            with open(toml_path, 'rb') as f:\n                config.update(tomllib.load(f))\n        except FileNotFoundError:\n            pass\n    \n    for key, value in env_mapping.items():\n        if key.startswith(env_prefix):\n            env_key = key[len(env_prefix):].replace('__', '.').lower()\n            config[env_key] = _coerce_value(value, defaults.get(env_key))\n    \n    return config\n\ndef _coerce_value(value, default):\n    if default is None:\n        raise ConfigError(f'No default for {value}')\n    \n    if isinstance(default, int):\n        return int(value)\n    elif isinstance(default, float):\n        return float(value)\n    elif isinstance(default, bool):\n        return value.lower() in ('true', '1', 'yes')\n    elif isinstance(default, str):\n        return value\n    else:\n        raise ConfigError(f'Unsupported type for {value}')\n"}}
