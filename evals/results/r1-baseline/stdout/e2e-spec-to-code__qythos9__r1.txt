## Overview

`envcfg` is a layered configuration loader that merges three sources—defaults, TOML, and environment variables—into a single dictionary. It enforces strict type coercion, reports all errors at once, and keeps the public API minimal.

## Layers and Precedence

1. **Defaults** – a plain dict supplied by the caller.
2. **TOML** – parsed with `tomllib`; missing files are silently ignored.
3. **Environment** – read via `os.environ` (or a custom mapping) using a prefix and `__` nesting.

Later layers override earlier ones key‑by‑key. A TOML entry that defines only a subset of keys leaves the rest of the defaults untouched.

## Keys and Nesting

Nested tables become nested dicts. To address a nested key from the environment, join the path with `__` and upper‑case it, prefixed by the caller’s prefix.  
Example with prefix `APP`:

- TOML key `server.port` → env var `APP__SERVER__PORT`.
- TOML key `database.credentials.password` → env var `APP__DATABASE__CREDENTIALS__PASSWORD`.

## Coercion Rules

Environment values are strings and must be coerced to match the type of the default value for that key. Supported types:

| Target type | Accepted env values (case‑insensitive) |
|-------------|----------------------------------------|
| `int`       | any valid integer string (e.g. `"42"`, `"-7"`) |
| `float`     | any valid float string (e.g. `"3.14"`, `"-0.5"`) |
| `bool`      | `true`, `false`, `yes`, `no`, `1`, `0` |
| `str`       | any non‑empty string (empty string is allowed) |

If coercion fails, the loader raises `EnvCfgError`. An env key that has **no** corresponding default is also an error (likely a typo).

## Error Reporting

All problems are collected and raised together as a single `EnvCfgError`. The exception carries a message that names the offending key and the expected type, e.g.:

- `"invalid integer for key 'server.port': got 'abc'"`
- `"unknown environment key 'APP__UNKNOWN'"`
- `"missing default for environment key 'APP__DATABASE__CREDENTIALS__PASSWORD'"`

## Public API

```python
def load(
    defaults: dict,
    toml_path: str | None = None,
    env_prefix: str = "APP",
    env: Mapping[str, str] | None = None,
) -> dict:
    """
    Merge defaults, TOML (if present), and environment variables.
    env may be None (use os.environ) or a custom mapping.
    Raises EnvCfgError on any coercion or unknown-key problem.
    """
```

- `defaults`: dict of base values.
- `toml_path`: optional path to a TOML file; missing file is ignored.
- `env_prefix`: string prefix for env vars.
- `env`: optional mapping of env var names to values; if omitted, `os.environ` is used.

## Implementation Constraints

- Python 3.10+ only.
- Standard library only (`tomllib`, `os`, `json`, `re`).
- Keep the module under ~150 lines.
- Provide comprehensive tests covering precedence, nesting, all coercion types, both error cases, and the missing‑file case.
