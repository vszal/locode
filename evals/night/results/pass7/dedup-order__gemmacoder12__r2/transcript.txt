The `dedup` function was using `sorted(set(items))`, which removes duplicates but returns the items in sorted order rather than the order of first appearance. The fix iterates through the items and appends each value to a result list only if it hasn't been seen yet, which preserves the original order of first occurrences.

```python
def dedup(items):
    seen = set()
    result = []
    for item in items:
        if item not in seen:
            result.append(item)
            seen.add(item)
    return result
```
